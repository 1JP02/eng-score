# 英语 Presentation 评分 · 使用说明

**两种打开方式（二选一）**

| 方式 | 说明 |
|---|---|
| 🌐 **公网网址**（推荐） | 打开 **https://1jp02.github.io/eng-score/** —— 手机、电脑都行，**不用装任何东西、不用传文件** |
| 💾 本地文件 | 双击 `英语Presentation评分表.html`（功能完全一样，适合没网/断网时用） |

评分项：内容 3 · 语言 3 · 互动 1 · 表现 3 = **满分 10 分**
等级：≥9 优秀 ｜ 8-8.9 良好 ｜ 6-7.9 合格 ｜ 小于 6 待提高

## 🏆 最终得分怎么算（简单平均）

**每位评委的分数都算数**：把所有已提交评委的总分相加，再除以提交人数。

- 例：3 人打分 9 / 8.5 / 10 → 最终得分 **(9 + 8.5 + 10) ÷ 3 = 9.17**
- 各评分项（内容 / 语言 / 互动 / 表现）也是同样算法：所有人该项的分数取平均
- **不去最高分、不去最低分**，打分板上每个人的分数都照原样显示、都计入结果
- 打分板底部那一行显示为「🏆 最终得分（N 人平均）」；归档卡片与 CSV 里的「最终得分」同样是这个平均分
- 导出的 CSV 里含：**最终得分（平均）**、以及每位评委的明细与 `评语汇总`

> 人数、小数的处理：平均分保留 2 位小数（如 9.17）；有人没提交就不计入分母，所以分母永远是"实际提交人数"。

## 一、学生怎么打分（扫码最快，3 步）

1. **扫主持人投屏/发在群里的二维码**（或打开公网网址、或打开群里的 HTML 文件）
   - 需要连网：校园网、手机流量、家里 Wi-Fi 都行，**不需要和主持人连同一个 Wi-Fi**
2. 扫码/点链接进来的会**自动进房间**；若手动打开，则：填房间码 → 点「**加入并开始打分**」
   - 名字可留空，自动分配「评委1、评委2…」，不会重名
3. **打分 → 点底部「提交」** —— 完成
   - 大号 **−/＋** 按钮打分（每次 0.5 分），也可直接输入数字
   - 想写评语：展开「**评语（可选）**」，可以写「亮点：……　建议：……」
   - 想看大家的分和评语：展开「**其他评委的分数与评语（N 人 · M 条评语）**」—— 上面是分数表格，下面是 💬 **评语明细**（谁、多少分、写了什么）
   - 🛡️ **防误触**：点提交会弹确认框（列出各项分数与总分），确认后才真正提交
   - ⚠️ **每人每场只能提交一次**：交完按钮会变成「已提交 ✓ 本场不能重复提交」，打分栏同时锁定，不能修改、也不能重复提交

主持人换下一位时（点「设为当前演讲人」），所有手机**自动清零并解锁**，可以给下一位重新打分。

> 学生界面里**看不到**主持人功能（按钮全部禁用、二维码区隐藏），只能打分和看分 —— **只有房主能控场**。

### 评语藏在哪三个地方（都能看每个人的评语）

| 位置 | 看到什么 |
|---|---|
| 打分页 →「其他评委的分数与评语」→ 💬 **评语明细** | 实时显示：**谁**（评委3）、**多少分**（10 分）、**写了什么**；按总分从高到低排 |
| 主持人工具 →「**已归档场次**」→ 点开某一场 | 每位评委的**各项得分 + 总分 + 评语**，没写评语的显示「（无评语）」 |
| 「导出汇总 CSV」 | `评语汇总` 一列，形如 `评委3：内容充实，结构清晰 ｜ 评委1：发音清晰，建议放慢语速` |

> 评语是**可选**的：只打分不写评语也能正常提交；写了的评语所有人都能看到（含没提交的人），所以请写得具体、友善一些。

## 一·五、房主（主持人权限）

- **建房的人自动成为房主**：只有房主的「设为当前演讲人 / 结束本场并归档 / 复制邀请信息 / 导出汇总 CSV / 二维码邀请」可用
- 其他人打开主持人工具时，只会看到一行提示：「房主：XXX　主持人功能仅房主可用」
- 房主身份**认人不认设备临时状态**：换页面/重开浏览器（同一台设备）仍然是房主；换设备则不是
- **房主不在怎么办**：其他人可以点「**接管房主权限**」（会弹确认框），接管后原房主立即失去权限，新房主获得全部功能

## 二、主持人（房主）怎么用

1. 打开页面 → 「加入评分房间 → 主持人：新建房间」→ 点「**新建房间并连接**」（**建房的人自动就是房主**）
2. 展开「主持人工具 → **二维码邀请**」：
   - 页面上会显示**二维码**（投屏给同学扫）和邀请链接
   - 点「**复制邀请链接**」发到班级群（不用再传文件了！）
3. 填「当前演讲人」→ 点「**设为当前演讲人**」
   - 这会**开始新的一场**：清空本场已提交的分数、所有人的手机自动清零并解锁
   - 若本场已有人提交，会先弹确认框（避免误清空）
4. 讲完 → 点「**结束本场并归档**」→ 本场平均分与**每位评委的评语**一起进历史，进入下一位
5. 全部结束 → 点「**导出汇总 CSV**」（Excel 直接打开，含每场平均分、评委明细与 `评语汇总` 列）

> 归档后可随时在「主持人工具 → 已归档场次」里点开任意一场回看：每人的分数 + 评语都在里面，写总结时特别方便。

页面顶部常显：房间码 · 我是谁 · 当前演讲人 · **同步状态**（"刚刚同步 / 12 秒前同步"）。

### 二维码指向哪里？

- 默认指向公网地址 `https://1jp02.github.io/eng-score/`（可在「主持人工具 → 二维码邀请 → 页面网址」里改）
- 二维码内容 = `页面网址?room=<房间码>&auto=1` → 同学扫码后**打开页面并自动加入该房间**

## 三、一个班 40+ 人同时打分（已压测通过）

**结论：40-50 人同时在线打分没问题**，已按最坏情况（全班同一秒一起提交）压测：

| 压测项 | 结果 |
|---|---|
| 45 个客户端同时连接 + 提交 | **1742 ms 全部完成，0 失败** |
| 主持端收到的提交数 | **45 人全部到齐**，最终得分（平均）计算正确 |
| 45 份分数的存量拉取（新加入的人） | **约 1.2 秒** |
| 主持人一键清场（45 条并发删除） | **2 ms 发出，4 秒内全部生效，0 残留** |
| 主机端 JS 错误 | **0** |

### 已做的高并发加固

| 措施 | 作用 |
|---|---|
| **渲染合并（180ms 节流）** | 全班同一秒提交时，无论收到多少条消息，界面最多每 180ms 重绘一次，低端手机也不会卡死 |
| **加入错峰 + 抖动** | 40 人同时扫码时，命名请求按在线人数排队，避免撞名风暴 |
| **重连随机抖动** | 网络抖动后全班不会"同一瞬间"重连 |
| **二维码缓存** | 只在房间码/网址变化时才重新计算二维码 |
| **过期名册丢弃** | 超过 6 小时的名册自动忽略，加入时的存量消息不会无限膨胀 |

### 给主持人的建议（人多时）

1. **每节课新建一个房间**（旧房间的保留消息会累积，新房间最干净）
2. 让同学**扫码进入**，比手动输房间码更不容易出错、也能错峰
3. 主持人页面顶部会显示「**在线 N 人**」，讲过一轮后看一眼是否到齐
4. 若某个时段公共中转服务器较慢，可在「主持人工具 → 中转服务器设置」切换：
   `ws://broker.hivemq.com:8000/mqtt`（明文更快）或 `wss://broker.emqx.io:8084/mqtt`
5. 主持人电脑/手机建议**插着电**并保持页面在前台（切后台省电模式可能暂停连接，切回来自动补同步）

**Q：显示"重连中…"？**
不用管，会自动重连（最多 8 秒一次），重连后自动补齐漏掉的数据。也可点「重新同步」手动拉取。

**Q：手机锁屏后再打开，分数没更新？**
切回前台会自动重连补同步；不放心就点一下「重新同步」。

**Q：连不上中转服务器？**
展开「主持人工具 → 中转服务器设置」，换成 `ws://broker.hivemq.com:8000/mqtt` 或 `wss://broker.emqx.io:8084/mqtt`。

**Q：房间码安全吗？**
房间码相当于房间口令（公共服务器上别人猜到房间码才能看到你们的数据），不要外传；每节课建议新建房间。

**Q：公网页面是公开的，会不会泄露？**
页面本身只是工具（不含任何数据），谁打开都要**知道房间码**才能看到分数。

**Q：完全没网怎么办？**
本工具现在**只支持云端联机**（需要能上外网，校园网/流量都行）。完全没有网络时无法联机打分，可用纸笔或口头收集。

## 四、技术说明

- 通过**免费公共 MQTT 服务器**（`wss://broker.hivemq.com:8884/mqtt`）中转，推送式实时同步，一条 WebSocket 长连接，无按请求配额
- 程序内置自研极简 MQTT 客户端 + 二维码生成库（`qrcode-generator`，MIT 协议），整个程序就一个 HTML 文件
- **每个评委用唯一 ID 作为主题**，名字只放在消息里 → 多人同时打分、甚至同名也不会互相覆盖
- 用**保留消息**保存状态 → 中途加入的人立刻看到已有分数；重连后自动重建全部状态
- 已内置：自动重连（指数退避）、心跳看门狗、乐观提交、回到前台自动补同步
- 公网页面托管在 GitHub Pages（仓库 `1JP02/eng-score`，公开），更新方式：告诉我即可重新部署
- 页面地址若变更（换了仓库或域名），改「二维码邀请 → 页面网址」即可，二维码会跟着变
